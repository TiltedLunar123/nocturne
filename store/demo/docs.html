Configuration

Every setting Meridian reads at startup, where it reads it from, and what happens when two sources disagree.

Configuration is resolved once, at boot, from three places. Later sources win over earlier ones, so a flag on the command line always beats a value in the config file.

# meridian.toml
[server]
listen   = "0.0.0.0:7700"
workers  = 8

[storage]
path     = "/var/lib/meridian"
fsync    = true
Note. Changing storage.path on a running node will not migrate existing data. Stop the node, move the directory, then restart.

Resolution order

SourceExamplePrecedence
Config filemeridian.tomlLowest
EnvironmentMERIDIAN_WORKERS=16Middle
Command line--workers 16Highest

Reloading

Send SIGHUP to reload the file without dropping connections. Settings marked static in the table above are ignored on reload and need a restart. See the operations guide for the full list.
