Stubborn sites

A few sites set colours directly on elements, marked so that no ordinary stylesheet can override them. Nocturne can win those by injecting its theme at user level instead, which outranks anything a page can write. This needs permission to act on all sites, which is why it is off by default and asks before turning on.

Per-site settings

No sites have their own settings yet. Change anything in the popup while on a site and it will appear here.

    Privacy

    Nocturne makes no network requests of any kind, and the build refuses to produce a package if any networking code appears in the source. It has no analytics, no accounts, and no remote configuration. Your settings stay in this browser.
